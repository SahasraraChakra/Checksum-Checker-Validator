Drop the TTF/OTF files for the design fonts here and they are loaded automatically at startup:
  Product Sans  (ProductSans-Regular.ttf, ProductSans-Bold.ttf)   -> UI font (falls back to Open Sans, Segoe UI)
  Open Sans     (OpenSans-Regular.ttf, OpenSans-Bold.ttf)
  JetBrains Mono (JetBrainsMono-Regular.ttf, JetBrainsMono-Bold.ttf) -> hashes / paths / numbers
Use static (non-variable) font files.
